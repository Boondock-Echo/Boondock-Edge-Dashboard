# Documentation Screenshots

This directory contains screenshots used in the documentation. Screenshots should be placed here and referenced in the documentation components.

## Screenshot Naming Convention

- `dashboard-overview.png` - Main dashboard overview
- `dashboard-sidebar.png` - Dashboard sidebar
- `dashboard-topbar.png` - Dashboard top bar controls
- `dashboard-messages.png` - Message list view
- `settings-summary.png` - Settings Summary tab
- `settings-recorders.png` - Settings Recorders tab
- `settings-global.png` - Settings Global tab
- `settings-system.png` - Settings System tab
- `settings-logs.png` - Settings Logs tab

## How to Add Screenshots

1. Take a screenshot of the desired interface
2. Save it as a PNG file with the appropriate name
3. Place it in this directory (`frontend/public/screenshots/`)
4. The screenshot will automatically be available at `/screenshots/[filename].png` in the application

## Screenshot Guidelines

- Use PNG format for best quality
- Recommended resolution: 1920x1080 or similar
- Keep file sizes reasonable (< 500KB per screenshot)
- Ensure screenshots are clear and readable
- Update screenshots when UI changes significantly
